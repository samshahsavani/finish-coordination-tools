# Public Screenshot Evidence

These screenshots are public-safe captures of the finish coordination tools running against the fictional sample workbooks in `../sample-data/`.

The originals live here as source-truth evidence. Optimized `.webp` copies for the website live in `05-Website/public/parkin-tools/`.

## Sets

- `qaqc-*`: Finish QAQC Auditor upload, mapping, rule definition, and exported audit report.
- `template-analyzer-*`: Finish Template Analyzer upload, grouping setup, summary, and exported workbook views.
- `template-finder-*`: Template Finder upload, column selection, filter selection, match narrowing, and selected template view.
- `room-type-*`: Room Type Analyzer upload, SDP reference selection, generated code review, summary, and exported reference workbook.
- `column-comparator-*`: Column Comparator upload, file selection, pair configuration, results summary, and exported comparison workbook.

## Public Use

- Use these screenshots for website and portfolio artifacts.
- Do not replace them with screenshots from `09-Codebases/private/parkin-finish-tools-original/files to test/`.
